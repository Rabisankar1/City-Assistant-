# 🌤️ City Assistant - AI Agent Web App

An intelligent full-stack AI Assistant built with **FastAPI** and **LangChain / AI Agents** that provides real-time weather updates and local news for any city with human-in-the-loop tool approval.

---

## ✨ Features
- 🌦️ **Real-time Weather & News**: Ask questions about any city's conditions or latest updates.
- ⚙️ **Human-in-the-Loop Tool Execution**: Interactive approval card allowing users to approve or deny tool actions.
- ⚡ **Auto-approve Mode**: Toggle to automatically execute tools without manual prompts.
- 🎨 **Modern Responsive UI**: Clean interface built with vanilla HTML, modern CSS, and JavaScript.

---

## 🛠️ Tech Stack
- **Backend**: Python, FastAPI, Uvicorn
- **AI & Tools**: LangChain / Custom Tools, Tavily Search API
- **Frontend**: HTML5, CSS3, JavaScript
